BUG-142: Discount code applied twice when “Apply” is double-clicked

High
Environment
Staging · Chrome 130 · macOS 15
Component
Checkout / Promotions
Reproducible
5/5

Steps to reproduce

  1. Add any item over $50 to the cart.
  2. Go to Checkout and enter code SAVE10.
  3. Double-click Apply quickly.

Expected

One 10% discount is applied; button is disabled while the request is pending.

Actual

Two POST /api/promo requests fire; 20% is deducted. Order total is wrong at payment.

Impact

Revenue loss on every affected order; easily discoverable by users.

Suggested fix

Disable the button on submit and make the promo endpoint idempotent per cart.

How this site is tested

tests/pages/HomePage.ts

import { type Page } from '@playwright/test';
import { NavBar } from './components/NavBar';
import { Toolbar } from './components/Toolbar';
import { HeroSection } from './components/HeroSection';
import { ContactSection } from './components/ContactSection';

export class HomePage {
  readonly nav: NavBar;
  readonly toolbar: Toolbar;
  readonly hero: HeroSection;
  readonly contact: ContactSection;

  constructor(readonly page: Page) {
    this.nav = new NavBar(page);
    this.toolbar = new Toolbar(page);
    this.hero = new HeroSection(page);
    this.contact = new ContactSection(page);
  }

  async goto(query = '') {
    await this.page.goto(`/${query}`);
  }
}
